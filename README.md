# Quiz Application

This is an interactive Quiz Application using HTML, CSS, and JavaScript. It fetches trivia questions from the Open Trivia Database API and offers an engaging experience with a timer and real-time feedback.

# Features:

Fetches 10 hard-level multiple-choice questions dynamically.
Timer for each question (20 seconds); timeout counts as incorrect.
Immediate feedback with correct and incorrect answers highlighted.
Displays final score and result summary at the end.

# How It Works:

1. Start the quiz from the landing page.
2. Read instructions, then begin the quiz.
3. Answer questions or let the timer run out.
4. View your score and results after completing all questions.
